# 轻播 Vela

一款简洁的本地音乐播放器，深色界面，装上就能放手机里的歌。

![界面](UI.jpg)

支持 Android 6.0 及以上系统。

---

## 能做什么

- 播放手机里的音乐和视频，也能播放网络地址（http/https 流）
- 后台播放：锁屏、通知栏、耳机线控都能切歌和暂停
- 四种播放模式：顺序播放、列表循环、单曲循环、随机播放
- 歌词自动匹配：本地歌词文件优先，没有就去网上找
- 没有封面的歌会自动配一张好看的图，并且每分钟换一张
- 收藏喜欢的歌，自己建歌单
- 关掉再打开，接着上次的进度继续放

## 怎么用

### 放歌

1. 打开应用，点左上角菜单进入 **我的 → 本地音乐**，点任意一首开始播放
2. 也可以点右上角 **打开**，从手机里选文件；或输入一个网络地址在线播放
3. 底部播放条随时能回到正在播放的歌

### 看歌词

- 在播放页**点一下封面**，就会切换到歌词页，当前唱到哪一行会自动高亮
- 再点一下歌词页的空白处（或再点封面），回到封面

### 歌词对不上？手动换

- 歌词页右上角有 **换源**，点开后会列出几个搜索结果，每条都标了来源、歌名、歌手和时长差
- **点一条就直接用这条歌词**，不用再点第二次；换好后马上就回到歌词页
- 选的这条会被记住，下次听同一首歌还用这条
- 想再搜一次，点列表左下角的 **重新搜索**；选错了可以点 **自动匹配** 恢复默认

### 歌词快一点或慢一点

- 歌词页右上角有 **-0.5s / 同步 / +0.5s**
- 歌词比声音快就点 `+0.5s`，慢了就点 `-0.5s`，最多调 20 秒
- 点 **同步** 归零；每首歌单独记住自己的调整

### 封面

- 歌里有封面就直接显示
- 没有的话，应用会先配一张装饰图，同时去网上找真封面，找到就自动换上
- 音频歌曲的封面**每分钟自动换一张**，暂停或切到后台时不换
- 第一次看某张装饰图需要联网，之后会存在手机里，断网也能继续轮换

### 收藏和歌单

- 播放页右下角的爱心可以收藏当前歌曲
- 首页 **我的** 里能看到本地音乐、我的收藏、我的列表
- 在「我的列表」里可以新建歌单、改名、删除、加歌、调整顺序、整张播放

### 搜索

- 首页搜索框可以按歌名或歌手找**手机里的歌**，会记住你搜过的词

### 设置

- 首页 **设置** 里可以改播放模式、切换明亮/暗色主题、切换中文/English，也能看到版本信息

## 一些说明

- 歌词来自网上的公开服务，不是官方接口，偶尔会搜不到或搜错，这时用 **换源** 手动挑最合适的一条
- 文件名写得清楚一些（例如 `歌手 - 歌名.flac`）更容易匹配到正确的歌词和封面；纯拼音或代号一样的文件名基本只能手动选
- 没有网络时：本地歌词和内嵌封面照常使用；已经下载过的装饰图仍然可以轮换
- 搜不到歌词、封面时先看看网络是否正常，多等几秒再试
- 「歌单」「排行榜」两个页面还没接入在线音乐，暂时是空的；自己建的歌单在 **我的** 里
- 收藏是按歌曲名字记录的，两首同名不同版本的歌会互相覆盖
- 歌词调整最多 ±20 秒

## 隐私

- 不投放广告，也不申请读取广告标识的权限
- 不需要注册或登录，不上传你的歌单和播放记录
- 联网只用于搜索歌词和封面
